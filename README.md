# Lenda

Simulador de carreira de jogador de futebol no navegador.

Cria o jogador (país, posição, camisa, perna), escolhe a base, decide entre temporadas e termina num quadro com as cores e o escudo do clube.

## Abrir

Dois cliques em `abrir.bat` (sobe um servidor local na porta 8765).

Ou, se já houver um servidor nessa pasta, abra `index.html`.
